# 全局 Wi-Fi / BLE 连接提醒弹窗设计

## 目标

当设备未连接 Wi-Fi，或系统中不存在任何已连接的 BLE 设备时，在应用任意页面上方显示统一连接提醒弹窗。弹窗使用 `assets/WifiBLE/` 中现有图片资源，视觉与提供的注册页效果图一致。

本次修改遵循最小范围原则：复用现有 `connectivity_plus`、`app_settings` 和 `universal_ble` 能力，不改动业务页面布局，不新增与连接提醒无关的重构。新增状态字段、生命周期处理和关键分支保留必要中文注释。

## 全局挂载方式

在 `GetMaterialApp.builder` 现有 `DesignCanvas` 内增加一个根级连接提醒 Host。Host 用 `Stack` 包裹 Navigator 子树，并把遮罩与弹窗放在最上层，因此登录、注册、首页及后续路由都共享同一个弹窗实例，无需逐页接入。

Host 负责应用生命周期监听、状态刷新和弹窗显示决策。连接检测逻辑放入独立控制器，UI 只消费状态并发出“打开设置”或“跳过”事件，便于单元测试。

## 连接状态判定

- Wi-Fi：`Connectivity.checkConnectivity()` 结果包含 `ConnectivityResult.wifi` 时视为已连接；这里只判断是否接入 Wi-Fi，不判断互联网是否可访问。
- BLE：`UniversalBle.getSystemDevices(withServices: [])` 返回至少一个系统已连接 BLE 设备时视为已连接。任意 BLE 设备均可，不校验名称、MAC 或 Service UUID。
- 两项均连接时不显示弹窗；任一项未连接或检测失败时显示对应未连接状态。
- Android 完整支持上述任意系统 BLE 连接检测。Apple 平台在没有 Service UUID 时存在系统 API 限制，本次不扩展目标设备识别协议。

状态在以下时机刷新：

1. 根级 Host 首次挂载后；
2. App 从系统设置等外部界面回到前台时；
3. Wi-Fi 网络类型发生变化时；
4. App 位于前台时每 5 秒读取一次系统 BLE 连接快照，以发现运行期间发生的新断线。

所有异步回调在更新 UI 前检查组件和控制器是否仍然有效，重复刷新合并处理，避免叠加检测或重复弹窗。

## “跳过”状态机

“跳过”表示本次 App 运行期间暂不提醒，不写入本地持久化存储。

- 首次检测到缺少连接时显示弹窗。
- 用户点击“跳过”后关闭弹窗，并将当前缺少连接事件标记为已跳过。
- 页面跳转、返回和 App 前后台切换不会让同一缺少连接事件重复弹出。
- 跳过期间仍继续刷新连接状态。
- Wi-Fi 与 BLE 后续都连接成功时，清除已跳过标记。
- 在两项都曾恢复连接后，如果任一项再次断开，视为新的断线事件，重新显示弹窗。
- App 完全退出并重新启动后，内存中的跳过标记自然清除；若仍缺少连接，再次显示弹窗。

若弹窗保持打开并从系统设置返回，状态立即刷新；两项均已连接时自动关闭弹窗。

## 弹窗交互与视觉

- 使用 `bg.png` 作为 448 × 480 的卡片背景，使用 `wifi.png`、`ble.png` 和 `enter.png` 作为行内图标。
- 标题、说明、两条连接状态行和底部“跳过”按效果图定位；状态圆点绿色表示已连接，红色表示未连接。
- 点击 Wi-Fi 行调用现有系统 Wi-Fi 设置入口；点击 BLE 行调用现有系统蓝牙设置入口。
- 遮罩拦截对下层页面的点击。点击遮罩和系统返回键均不关闭弹窗，只能点击“跳过”或在两项连接成功后自动关闭。
- `assets/WifiBLE/` 补入 `pubspec.yaml` 资源声明。
- 首页现有测试按钮改为强制打开同一个全局弹窗并展示当前状态，不再导航到独立的 `/wifi-bluetooth` 页面；手动打开时即使两项已连接，也由用户点击“跳过”关闭，便于现场查看和测试。

## 错误处理

连接状态读取失败时不崩溃，失败项按未连接展示。打开系统设置失败时保留弹窗并记录调试日志，不改变跳过状态。异步检测完成前显示检测中状态，避免短暂地把未知状态误报成已连接。

## 测试与验证

采用测试驱动方式覆盖：

- Wi-Fi 或 BLE 任一缺失时显示，两项均连接时不显示；
- 点击“跳过”后，跨页面导航和前后台切换不重复显示；
- 跳过后两项恢复连接会清除跳过状态，随后新的断线重新显示；
- 从系统设置返回后刷新状态，两项连接成功时自动关闭；
- Wi-Fi/BLE 行分别调用正确的设置动作；
- 弹窗使用指定资源、状态文字和不可点击穿透的遮罩；
- `flutter analyze` 与相关 Widget/单元测试通过。

视觉验收以 800 × 1280 和 1280 × 720 两种现有设计画布配置检查居中、尺寸、文字和遮罩效果。
