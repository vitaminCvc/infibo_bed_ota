# Infibo 共用 APK 打包工具

双击本项目根目录的 启动APK打包工具.cmd，会打开旧项目中同一个共用工具。勾选「官方版 OTA」或「国内测试版 OTA」即可从 infibo_ota 构建；其他选项从旧项目构建。保存目录按各选项独立记忆。

旧项目与 infibo_ota 保持相邻。共用工具的完整说明位于 ../infibo_app_v1.0_1610/tool/apk_packager/README.md。

此目录保留复制时的旧脚本，日常使用请从根目录的启动文件打开共用工具。

共用工具现已增加“取消打包”：可停止当前构建和后续排队版本，保留已经完成的 APK 及成功编号记录。取消后可以重新开始。请重新打开根目录入口使用新版界面，已打开的旧窗口不会自动更新。
